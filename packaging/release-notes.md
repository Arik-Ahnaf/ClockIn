## Install

**Windows (64-bit)**
1. Download `ClockIn-1.0.0-windows-x86_64.zip` below and extract it.
2. Open the extracted `ClockIn` folder and launch **ClockIn.exe**.

**Arch Linux (64-bit)**
1. Download `clockin-1.0.0-1-x86_64.pkg.tar.zst` below.
2. From your download folder, run:
   ```sh
   sudo pacman -U ./clockin-1.0.0-1-x86_64.pkg.tar.zst
   ```
3. Open **ClockIn** from your application launcher, or run `clockin`.

For portable Linux use, extract `ClockIn-1.0.0-linux-x86_64.tar.gz` and run `./ClockIn/ClockIn`. Linux builds target Arch Linux with X11/XWayland and require the desktop libraries described in the [installation guide](https://github.com/Arik-Ahnaf/ClockIn#installing).

Python is included. Keep the entire extracted application folder together.

## Set up your first timer

1. Click **Add timer** at the bottom of the window, or press **Ctrl+N**.
2. Enter the hours, minutes, and seconds—for example, **00:05:00** for five minutes.
3. Click the **Set timer** button (save icon).
4. Click **Play** on the new timer card to start the countdown. Drag the floating timer to position it; click its surface to reveal the pause control.
