## Changelog

- Floating timers stay on top of other windows by default, independently of the main ClockIn window.
- Added **Settings → Timers stay on top** to toggle this behavior on or off while the app is running.

## Downloads

- **Windows x64:** extract the ZIP and launch `ClockIn.exe` inside the extracted folder.
- **Linux x86_64:** extract the tarball and launch `ClockIn/ClockIn`. This build targets Arch Linux with X11/XWayland.
- **Arch Linux package:** install the `.pkg.tar.zst` with `sudo pacman -U <filename>`.

Keep the complete application folder together. Python is bundled. SHA-256 checksums are provided in `SHA256SUMS.txt`.
